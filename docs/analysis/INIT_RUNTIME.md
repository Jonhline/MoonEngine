# Reference execution prototype

Implementation: `src/ee/ and tests/initsys/`.

The reference tools execute selected original startup paths through locally recompiled routines and a bounded runtime. They are useful for validating structures and control flow; they do not form the playable game or a complete console implementation.

## Evidence and limitations

The [development record](../notes/analysis/INIT_RUNTIME.md) retains addresses, experiments,
test results and outstanding limitations. Older entries describe the state
