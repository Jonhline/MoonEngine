# GT Mode interface

The native menu bridge runs the disc's GT Mode Adhoc scripts on the widget
trees from its menu project. Career objects expose profile, garage, license,
event and calendar data; native drawing supplies models, bitmap animations,
text and modal composition.

The [development record](notes/GT_MODE_UI.md) preserves the map, navigation
and presentation findings. Older entries may be superseded. Consult
[Fidelity](FIDELITY.md) for the scope of individual comparisons; navigating
to a screen does not establish every action or pixel on it is verified.
