# Development notes

This is the development log, separate from the explanatory guides in
[the documentation index](../README.md). Entries retain original function
addresses, asset offsets, test commands, positive results, intentional
negative cases and known limitations. Some records are in Portuguese.

Dates identify when evidence was recorded, not a guarantee of the current
implementation. Later records may supersede earlier findings. Read the
per-item grade and scope in [Fidelity](../FIDELITY.md) before treating a test
result as proof. Disc files, captures and generated original-code outputs
remain local and are not part of these notes.
