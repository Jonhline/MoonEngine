# Replay and photo media coverage

Native replay files, imported console media and undeveloped-film data have separate decoding and reconstruction paths. Command decoding, scene reconstruction and a complete rendered image require distinct comparisons. Coverage must be checked by replay class and media format, not inferred from one successful import.

## Evidence and limitations

The [development record](notes/PHOTO_MEDIA_COVERAGE.md) retains source addresses,
experiments, positive and negative cases, and historical limitations.
