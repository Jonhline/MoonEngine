# Career race lifecycle

Career scripts request a race with event, car and profile data. Native setup builds the race; result processing updates records, credits, awards and persistent profile state. Tests of setup, payout, progression and return to menus are distinct from whole-race presentation checks.

## Evidence and limitations

The [development record](notes/CAREER_CYCLE.md) retains source addresses,
experiments, positive and negative cases, and historical limitations.
Consult [Fidelity](FIDELITY.md) for each comparison's grade and scope.
Earlier entries may be superseded by later results.

The [continuous validation audit](notes/CAREER_VALIDATION_20261014.md) separates
shared-profile physical runs, controlled fixtures, failed championships and
remaining mission/licence evidence.
