# Project roadmap

The project first validates the original game, then adds improvements to
the same game (on by default, with an Original preset) and a later Tourist Trophy extension. These are
development stages, not promises of completed functionality.

See [Editions](EDITIONS.md) for the scope of each stage, [Mods](MODS.md)
for the proposed content workflow and [Fidelity](FIDELITY.md) for measured
coverage. The [historical roadmap](notes/ROADMAP.md) preserves earlier plans;
dated statements there may be superseded.
